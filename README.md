This entry is a program that writes one image to the output directory, capturing the happiest moment for the judge: a laughing little girl in a yellow dress placing a crown of sunflowers and daisies on the head of her white-bearded grandfather, who sits on a garden bench laughing with his hands raised in delight, while a small happy brown dog sits beside them wagging its tail, all in warm golden-hour light.

## Run It

To run the program locally and write the image into an `out` directory:

```bash
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
